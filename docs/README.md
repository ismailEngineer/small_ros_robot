### Motor Control Driver — TB6612FNG

The robot uses a dual H-bridge motor driver based on the TB6612FNG :contentReference[oaicite:0]{index=0} to control the two DC motors (left and right wheels). This component allows the ESP32-S3 microcontroller to regulate both the direction and speed of the motors using low-voltage logic signals, while providing the necessary current to drive the motors safely.

The TB6612FNG integrates two independent H-bridges in a single chip, meaning it can control two DC motors simultaneously. Each motor channel is controlled using direction inputs (IN1/IN2 or PH/EN configuration depending on the wiring choice) and a PWM signal generated by the ESP32-S3 to regulate speed. A standby pin (STBY) is used to enable or disable the driver, which is useful for safety, power saving, and ensuring a clean startup sequence.

On the PCB, the driver is powered from two separate power rails. The logic supply (VCC = 3.3V) powers the internal control circuitry, while the motor supply (VM) is connected directly to the LiPo 2S battery. To ensure stable operation, proper decoupling is required close to the chip: a 100 nF ceramic capacitor for high-frequency noise filtering and a bulk capacitor (typically 100 µF to 470 µF) to handle current spikes generated by motor switching.

Each motor output is connected to a DC motor equipped with an incremental encoder. The encoder signals are read by the ESP32-S3 to estimate wheel speed and position, enabling closed-loop control using PID regulation. This setup ensures precise motion control, stable low-speed behavior, and accurate odometry, which is essential for ROS2-based navigation and mapping on the host computer.

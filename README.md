# Small Robot ROS Project

This repository contains the full development stack for a small autonomous robot, including mechanical design, electronics, embedded firmware, and ROS-based software.

The goal of this project is to build a complete robotics system from hardware to high-level control, integrating mechanical design, PCB development, embedded programming, and ROS-based autonomy.

---

## 🧠 System Overview

The robot is composed of four main layers:

- **Mechanical system**: physical structure, chassis, and assembly
- **Electronics**: PCB design, wiring, and hardware integration
- **Firmware**: embedded control (motors, sensors, communication)
- **ROS stack**: high-level control, perception, simulation, and navigation

---

## 📁 Repository Structure

docs/ → Project documentation and system design
mechanics/ → Mechanical CAD files and manufacturing data
electronics/ → Schematics, PCB designs, and wiring
firmware/ → Embedded code (ESP32 / Arduino)
ros/ → ROS workspace (URDF, nodes, launch files)
tools/ → Development and automation scripts
tests/ → Hardware, firmware, and ROS tests



---

## ⚙️ Technologies Used

- ROS (Robot Operating System)
- C / C++ (Embedded systems)
- Arduino / ESP32
- KiCad (PCB design)
- CAD software (Fusion 360 / SolidWorks)
- Python (ROS nodes and tools)
